# comandos para crear modulos 
```bash
pnpm dlx @nestjs/cli@latest g module users
pnpm dlx @nestjs/cli@latest g controller users --no-spec
pnpm dlx @nestjs/cli@latest g service users --no-spec

pnpm dlx @nestjs/cli@latest g module roles
pnpm dlx @nestjs/cli@latest g controller roles --no-spec
pnpm dlx @nestjs/cli@latest g service roles --no-spec

pnpm dlx @nestjs/cli@latest g module permissions
pnpm dlx @nestjs/cli@latest g controller permissions --no-spec
pnpm dlx @nestjs/cli@latest g service permissions --no-spec
```
